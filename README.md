# Homebrew tap for Hearth

```bash
brew tap BobStrogg/hearth
brew install hearth
brew services start hearth
```

The release workflow in [BobStrogg/hearth](https://github.com/BobStrogg/hearth) bumps `Formula/hearth.rb` on every `v*` tag (needs a `HOMEBREW_TAP_TOKEN` secret with write access to this repo). Until the first release is published to npm, the sha256 above is a placeholder.
